### 2.2 设备列表视图

**默认视图：按房间分组**
- 每个房间为一个可折叠区域
- 房间内有该房间的所有设备
- 设备按"最近操作>有异常>常用>其他"排序
- 房间数量多时，自动折叠次要房间，只展开有活跃设备的房间

**切换视图：按设备类型**
- 点击"按类型查看"切换到设备类型分组
- 如：空调（3台）、灯光（5个）、安防（4个）...
- 同一类型设备集中展示，方便批量操作
- 再次点击可切回按房间分组

### 2.3 手机服务卡片（华为式）

**保留的通用服务（4个）：**
- 🌤️ 天气卡片 — 日常高频
- 📅 日程卡片 — 今日日程、提醒
- 📦 快递卡片 — 物流跟踪
- ✈️ 出行卡片 — 航班/火车

**砍掉的通用服务（2个）：**
- ❌ 健康卡片 — 格力不做健康生态
- ❌ 停车卡片 — 低频+耗电

**展示规则**：所有卡片动态展示，有内容时出现，无内容时自动收起。

### 2.4 格力特有服务

| 服务 | 说明 | 触发条件 |
|------|------|---------|
| 🧹 清洗服务提醒 | 空调清洗到期提醒 | 按使用时长自动触发 |
| 🔄 以旧换新 | 旧家电折价换新入口 | 常驻入口，可点击查看详情 |
| 🛒 天气联动产品推荐 | 天热推空调/风扇，天冷推取暖器，潮湿推除湿机 | 根据天气数据自动匹配 |
| 📊 数据报告摘要 | 用电/用水/食材报告入口 | 常驻入口 |

### 2.5 交互设计

| 元素 | 交互 | 说明 |
|------|------|------|
| 设备开关/滑块 | **直接操作** → 即时生效 | 调温、开关、亮度，无需跳转 |
| 设备卡片 | **点击** → 展开详情 | 系统级浮层，不跳转APP |
| 房间标题 | **点击** → 折叠/展开 | 房间较多时可管理 |
| 视图切换按钮 | **点击** → 切换房间/类型视图 | 两种视图 |
| 服务卡片 | **点击** → 跳转对应服务 | 天气→天气APP，日程→日历 |
| 格力服务卡片 | **点击** → 跳转功能页 | 以旧换新→商城页 |
| 搜索框 | **点击** → 展开全屏搜索 | 搜索设备/APP/服务 |
